Write up what we just worked through as a learning note.

Topic: $ARGUMENTS (if empty, infer it from the conversation)

1. Decide the file: `notes/<topic>.md`. If it exists, extend it rather than
   overwriting — add a new `##` section, keep what is there.
2. Keep it short. Structure:
   - **What it is** — two or three sentences.
   - **How it works** — the mechanism, with the smallest runnable example.
   - **Gotcha** — the thing that actually tripped me up, if anything did.
   - **Source** — link to the primary doc.
3. Use the real code from this session, not an idealised version of it.
4. Show me the diff and stop. Do not commit.
