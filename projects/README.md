# Projects

Larger end-to-end builds. Each folder is **self-contained** — its own `go.mod`, its own
README explaining what it teaches and how to run it.

When the first project lands, add a `go.work` at the repo root so the lessons module
and every project resolve together:

```sh
go work init . ./projects/<name>
```

Ideas live in [ROADMAP.md](../ROADMAP.md) (Level 4 and the Level 5 capstones).
